# Glint

Маленькая «пилюля» вверху по центру экрана для Windows 10/11. Показывает время, то, что сейчас играет, погоду и живые индикаторы, в ней живёт маленький персонаж, а при наведении она раскрывается в панель с быстрыми инструментами.

## Возможности

- **Пилюля** с часами, обложкой трека и индикатором воспроизведения; короткие всплывающие сообщения («Скопировано», «Таймер готов»). Индикатор оживает и для плееров, которые не сообщают Windows о воспроизведении: Glint замечает, что приложение играет звук.
- **Персонаж** (Настройки → Персонаж): семь своих героев — Пух (круглый с завитком), Усик (ушастый с усами), Бу (призрак), Болтик (робот с экраном вместо лица), Желе (блестящая капля), Искра (звёздочка), Росток (фасолинка с листиками) — или никого. Сидит слева или справа в пилюле, три размера, можно красить в цвета темы.
  - Следит глазами за курсором, когда тот рядом с пилюлей; моргает и иногда оглядывается.
  - Танцует под музыку: подпрыгивает в такт громкости того, что играет, покачивается, поёт и иногда выпускает ноту.
  - Пока работает Claude Code или Codex (см. «Агенты»), задумывается — над головой бегут точки-мысли; когда агент ждёт ответа, показывает «!», когда закончил — радуется, при ошибке огорчается.
  - Без мыши и клавиатуры засыпает (закрытые глаза, «Zzz») через 2–30 минут на выбор (агент, который столько же молчит, сну не мешает) и просыпается от первого движения или нового события агента.
  - Бережёт процессор: когда ничего не происходит, не перерисовывается вовсе; анимации — не больше 24 кадров в секунду и только в его маленьком квадрате (танец идёт в те же кадры, что и эквалайзер), а пока пилюля скрыта, раскрыта, показывает сообщение или компьютер заблокирован, всё стоит. Через минуту сна замирает совсем. Включён по умолчанию (Пух), выключается выбором «Нет».
- **Панель при наведении** с вкладками: Главная, Буфер, Полка, Текст, Заметки, Погода, Система, Пульт, Агенты (появляется, когда подключены агенты), Настройки. Можно закрепить, чтобы не сворачивалась. Если в шапке мало места, вкладки сжимаются до значков.
- **Пульт** (вкладка «Пульт»): включение и выключение Wi-Fi и Bluetooth, сопряжённые Bluetooth-наушники и колонки с подключением и отключением в одно нажатие, VPN-подключения Windows (из «Параметры → Сеть → VPN») с подключением и отключением, переключение тёмной и светлой темы Windows и темы самого Glint. Данные обновляются только пока вкладка открыта.
- **Медиа и громкость**: управление любым плеером, который поддерживает системные медиаэлементы Windows; ползунок громкости и отключение звука.
- **Быстрые действия** на «Главной»: скриншот, весь экран, запись экрана, текст с экрана, QR-код, пипетка, командная строка, блокировка, папка загрузок, а под ними — док закреплённых приложений. Закрепить приложение можно кнопкой «+», перетащив ярлык на док или правым кликом по приложению в командной строке.
- **Инструменты экрана** (на «Главной», в командной строке — «скриншот», «весь экран», «qr», «текст с экрана», «пипетка», «запись» — и в меню трея). Экран на мгновение «замораживается», и вы выбираете на неподвижной картинке: тянете рамку, щёлкаете по окну, чтобы взять его целиком, или жмёте Enter — весь монитор. Пилюля и открытая панель в кадр не попадают.
  - Скриншот с пометками: после снимка открывается редактор — перо, маркер, стрелка, прямоугольник, эллипс, текст, скрытие области пикселизацией, обрезка, семь цветов и три толщины, отмена и повтор (Ctrl+Z / Ctrl+Y), клавиши P H A R E T B C. «Копировать» (Ctrl+C) кладёт картинку в буфер, «Сохранить» (Ctrl+S) — PNG в «Изображения\Glint» и в буфер, «…» — сохранить как PNG или JPEG. Редактор можно отключить: тогда снимок сразу копируется и сохраняется.
  - QR-код и штрихкоды (QR, Data Matrix, Aztec, PDF417, EAN, UPC, Code 128/39, ITF): результат с кнопками «Копировать» и «Открыть ссылку»; для QR с Wi-Fi — имя сети и «Копировать пароль».
  - Текст с экрана: распознавание встроенным в Windows OCR, без интернета. Русский и английский читаются вместе (строки на латинице берутся из английского распознавания). Текст сразу копируется и показывается в окошке, где его можно поправить. Если в Windows нет ни одного языка с распознаванием, Glint подскажет, где его добавить.
  - Пипетка с лупой: увеличенные пиксели вокруг курсора с сеткой, рамка на центральном пикселе, HEX и RGB. Клик копирует HEX, Ctrl+клик — `rgb(…)`, стрелки двигают курсор на пиксель (с Shift — на десять), Esc отменяет.
  - Запись экрана в MP4: щёлкните по монитору или выделите область. Видео H.264 кодирует видеокарта (если умеет), звук системы — AAC; 30 или 60 кадров. Пока идёт запись, в пилюле красная точка с таймером, клик по ней останавливает запись (ещё — плитка «Стоп» на «Главной», чип в шапке панели, командная строка и трей). Файл ложится в «Видео\Glint», по окончании — сообщение, клик открывает видео.
- **История буфера обмена**: текст и картинки, поиск, закрепление, вставка в предыдущее окно по клику.
- **Полка файлов**: перетащите файлы на пилюлю, чтобы отложить их, и вытащите обратно в любое приложение.
- **Заметки** (вкладка «Заметки»): папки (создать, переименовать двойным кликом или правой кнопкой, удалить — заметки при этом остаются), список заметок, редактор с форматированием: жирный, курсив, подчёркнутый, зачёркнутый, заголовки, маркированный и нумерованный списки, чек-лист (клик по квадратику отмечает пункт), цвет текста из акцентов темы. Поиск сразу по всем заметкам. Сохраняются сами через секунду после того, как вы перестали печатать, а также при переключении заметки, вкладки и при выходе. Заметку можно перетащить на папку. Удалённую можно вернуть кнопкой «Вернуть», а файл ещё 30 дней лежит в `notes\deleted`.
- **Погода** (вкладка «Погода», включается в «Настройки → Погода», выключена по умолчанию): город ищется по-русски, после выбора рядом с часами появляются свой значок погоды и температура (если в пилюле тесно — они по очереди сменяются с часами). На вкладке — сейчас (ощущается как, ветер, влажность), полоса на 24 часа с вероятностью осадков и прогноз на 7 дней. Примерно за час до дождя или снега — сообщение «Через ~40 мин дождь», один раз на каждый дождь; клик открывает вкладку. Прогноз обновляется раз в 30 минут, пока погода включена, и хранится в `weather.json`, чтобы после перезапуска и без интернета было что показать. Данные — Open-Meteo, без ключа и регистрации.
- **Голосовой ввод**: кнопка с микрофоном во вкладке «Текст» (текст встаёт в редактор у курсора) и в командной строке (продиктованное становится запросом), «диктовка» в командной строке и необязательная горячая клавиша (Настройки → Голосовой ввод) — текст вставляется в окно, где вы печатали, так же, как вставляет история буфера, а прежнее содержимое буфера потом возвращается на место. Пока Glint слушает, в пилюле пульсирует микрофон и видна фраза, которую он сейчас разбирает; клик по ней, повторное нажатие или пауза заканчивают диктовку. Распознаёт Windows: нужен установленный язык речи и включённое «Распознавание речи в сети». Если чего-то не хватает, Glint скажет, что именно, и по клику откроет нужную страницу параметров, а пока откроет голосовой ввод Windows (Win+H).
- **Командная строка** (Alt+Space): поиск приложений и файлов, калькулятор, таймеры и напоминания, курсы валют, быстрые заметки и поиск по заметкам, погода («погода»), голосовой ввод («диктовка» и кнопка с микрофоном), поиск в интернете.
  - Напоминания обычными словами: «напомни через 10 минут позвонить маме», «напомни в 18:30 забрать посылку», «напомни завтра в 9 созвон», «напомни в пятницу в 7 вечера кино», «напомни 25.12 в 10:00 подарки», «напомни позвонить маме через час»; по-английски — «remind me tomorrow at 9am to call mom». Таймеры: «таймер 25 мин», «1ч 30м». Напоминания переживают перезапуск; те, что пришлись на время, когда Glint был закрыт, показываются при следующем запуске. Срабатывают сообщением в пилюле со звуком. Ближайшие видны на «Главной» с кнопкой отмены, все — в «Заметки → Напоминания»; там же их можно добавить.
  - Валюты: «100 usd», «100$ в руб», «50 евро to usd», «2,5к юаней», «курс евро», «курс» (доллар, евро и юань). Курсы ЦБ РФ; включаются в настройках или прямо из командной строки (выключено по умолчанию, см. «Данные и приватность»). Enter копирует результат.
  - Быстрая заметка: «заметка купить хлеб» сохраняет её в «Заметки»; любой запрос от трёх букв ищет и по заметкам.
- **Инструменты для текста**: исправление раскладки (ghbdtn → привет), транслитерация, смена регистра, форматирование JSON, Base64, диктовка в редактор.
- **Нагрузка на систему** (вкладка «Система»): процессор (общая загрузка, по потокам, частота), видеокарта, память, диски, сеть и самые активные процессы, графики за последнюю минуту. На видеокартах NVIDIA ещё температура, видеопамять, питание и вентилятор. Температуры процессора нет: Windows отдаёт её только драйверам ядра, а Glint их не ставит. Замеры идут только пока вкладка открыта.
- **Цветовые темы** (Настройки → Оформление): тёмная, светлая или «как в Windows» (Glint переключается вместе с системой), семь готовых пресетов (Аврора, Закат, Океан, Лайм, Роза, Уголь, Моно), свои цвета акцентов в HEX, оттенок и прозрачность фона. В светлой теме слишком бледные акценты чуть затемняются, чтобы текст читался. Всё меняется сразу, без перезапуска, включая значок и меню в трее.
- **Индикаторы в пилюле** (Настройки → Индикаторы, каждый включается отдельно): маленькие цветные значки рядом с часами и чипы с подробностями в шапке панели.
  - Микрофон и камера: точка, пока ими пользуется любое приложение, и короткое сообщение, кто именно (из того же реестра, по которому Windows рисует свой значок конфиденциальности).
  - Caps Lock и смена раскладки: вспышка «Caps Lock вкл», «RU · Русский». Glint смотрит только коды Caps Lock, модификаторов и пробела, набранный текст он не видит и не хранит.
  - Загрузки браузера (Chrome, Edge, Firefox, Opera — по временным файлам в папке «Загрузки»): значок с объёмом и скоростью, по окончании «Загружено: имя файла», клик открывает файл в проводнике.
  - Загрузки Steam: название игры и прогресс из манифестов библиотек, сообщение по завершении.
  - Запись OBS: красный значок, пока растёт файл в папке записей из профиля OBS; по желанию — точнее через obs-websocket (только localhost, пароль хранится зашифрованным DPAPI).
  - VPN: значок, пока поднят VPN-адаптер (WireGuard, OpenVPN, SSTP, Wintun и т. п.) или через виртуальный адаптер идёт весь трафик; адаптеры, которые не VPN (например, sb-discord), можно исключить в «Не считать VPN»; по желанию — внешний IP и страна.
  - Уведомления Windows: приложение и заголовок новых уведомлений коротко в пилюле; молчит в режиме «Не беспокоить», в полноэкранном режиме и для приложений, которым уведомления выключены в Windows (выключено по умолчанию).
  - Текст песни: синхронизированная строка для текущего трека с lrclib.net — рядом с часами и на вкладке «Главная» (выключено по умолчанию).
- **Агенты для кода: Claude Code и Codex** (Настройки → Агенты, выключено, пока вы не подключите агента).
  - Рядом с часами — чип самой срочной сессии: папка проекта и состояние («работает», «ждёт вас», «готово», «ошибка»), «+1», если сессий несколько; точка мягко пульсирует, пока агент работает. Клик открывает вкладку «Агенты» со всеми сессиями: что агент делает сейчас, сколько времени в этом состоянии, кнопка «Показать терминал».
  - Запрос разрешения (команда, правка файла, адрес, инструмент MCP, утверждение плана) превращает пилюлю в карточку: что именно агент хочет сделать и кнопки «Разрешить», «Всегда» (правило, которое предлагает сам Claude Code), «Запретить» и «В терминале». На вопросы Claude Code с вариантами ответа (в том числе несколько вопросов подряд и с выбором нескольких вариантов) можно ответить кнопками там же. Несколько запросов идут по очереди, «1 из 3». Если не ответить за выбранное время (по умолчанию 2 минуты), агент спросит в терминале как обычно; когда терминал агента и так на переднем плане, Glint запрос не перехватывает.
  - Сообщения «Готово · проект» с первой строкой ответа и «Ждёт вас · проект», когда агент ждёт в терминале; клик выводит терминал на передний план. Не показываются, если вы и так смотрите в этот терминал.
  - Подключение — кнопки «Подключить Claude Code» и «Подключить Codex». Перед записью Glint показывает, какой файл изменится и что именно добавится, сохраняет копию файла рядом (`*.glint-backup-<дата>`) и не трогает остальные настройки и ваши хуки; повторное подключение ничего не дублирует, «Отключить» убирает только записи Glint. Claude Code получает хуки в `%USERPROFILE%\.claude\settings.json`; Codex — хуки и `notify` в `%USERPROFILE%\.codex\config.toml` (новые хуки Codex запускает после того, как вы отметите их доверенными в `/hooks`).
  - Если Glint не запущен или приём событий выключен, хук завершается за миллисекунды без ответа, и агент работает так, будто Glint нет.
- **Скрытие в полноэкранных приложениях** и в выбранных программах.
- **Поведение** (Настройки → Поведение и Вид): положение пилюли вдоль верхнего края (перетащите её или шапку панели, двойной клик — в центр), задержка раскрытия, размер пилюли от 80 до 200 %; автоскрытие — пилюля уезжает за верхний край и оставляет тонкую полоску, возвращается при наведении на полоску и при любом сообщении; режим «пропускать клики» — пилюля не перехватывает мышь (удобно, когда она над вкладками браузера), а с зажатым Ctrl снова откликается. Настройки всегда доступны из значка в трее, там же выключается этот режим.
- **Значок в трее** с меню (скриншот, запись экрана, Заметки, Погода, Пульт, Агенты, Настройки, «Пропускать клики», автозапуск, пункт о найденном обновлении).

## Скачать

[**Glint.exe**](https://github.com/sempik/glint/releases/latest/download/Glint.exe) — один файл, установка не нужна, .NET ставить не надо. Просто запустите. Есть и [zip-архив](https://github.com/sempik/glint/releases/latest/download/Glint-win-x64.zip); контрольные суммы в `SHA256SUMS.txt` на странице [релиза](https://github.com/sempik/glint/releases/latest).

Файл не подписан платным сертификатом, поэтому Windows SmartScreen может предупредить при первом запуске: «Подробнее» → «Выполнить в любом случае». Сборки делает GitHub Actions прямо из этого репозитория.

**Обновление:** Настройки → «Проверить обновления». Glint скачает новую версию с этой страницы релизов, сверит контрольную сумму и перезапустится сам. Если Glint лежит в папке без прав на запись (например, Program Files), откроется страница релиза для ручного скачивания. По желанию можно включить «Проверять обновления автоматически» (выключено по умолчанию): тогда Glint проверяет при запуске и раз в 6 часов и показывает в пилюле «Доступно обновление»; по клику откроется кнопка установки в настройках. Устанавливается обновление только по вашему нажатию.

## Требования

- Windows 10 версии 2004 (сборка 19041) или новее, либо Windows 11, x64

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
git clone https://github.com/sempik/glint.git
cd glint
dotnet build
```

Один exe-файл для распространения:

```powershell
dotnet publish src/Glint/Glint.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```

Готовые сборки появляются в [Releases](https://github.com/sempik/glint/releases) автоматически при пуше тега `v*`.

## Данные и приватность

Все настройки, история буфера, полка, заметки, напоминания и последний прогноз погоды хранятся локально в `%AppData%\Glint`. Никакой телеметрии, аналитики и сетевых запросов, кроме тех, что вы запускаете сами (например, поиск в интернете из командной строки или проверка обновлений кнопкой в настройках), и функций ниже, которые вы включаете сами.

**Автопроверка обновлений** (Настройки → О программе, выключена по умолчанию): при запуске и затем раз в 6 часов один запрос к `api.github.com` (`/repos/sempik/glint/releases/latest`); GitHub видит ваш IP и версию Glint в User-Agent. Без этой галочки Glint обновления сам не проверяет.

**Курсы валют** в командной строке (Настройки → Командная строка, выключены по умолчанию): когда вы вводите запрос вроде «100 usd», Glint берёт курсы ЦБ РФ с `www.cbr-xml-daily.ru` (если сервис не ответил — с `open.er-api.com`), не чаще раза в 6 часов, и хранит их в `rates.json`. Сервис видит ваш IP, но не то, что вы считаете. Пока функция выключена, командная строка только предлагает её включить.

**Погода** (Настройки → Погода, выключена по умолчанию): поиск города — запрос к `geocoding-api.open-meteo.com` с тем, что вы ввели, только когда вы нажимаете «Найти». Когда город выбран, Glint при запуске (если сохранённый прогноз старше 30 минут) и затем раз в 30 минут запрашивает прогноз у `api.open-meteo.com`, отправляя только координаты города. В настройках хранятся название и координаты, прогноз — в `weather.json`. Предупреждение о дожде считается из уже полученного 15-минутного прогноза, отдельных запросов нет. Пока погода выключена, Glint в сеть за ней не ходит и таймеров не держит.

**Голосовой ввод** работает только по вашему нажатию (кнопка или горячая клавиша, которая по умолчанию не задана). Речь распознаёт Windows (`Windows.Media.SpeechRecognition`): с включённым «Распознаванием речи в сети» звук обрабатывает служба Microsoft по правилам Windows, сам Glint звук не записывает, не хранит и никуда не отправляет. Микрофон открыт только пока идёт диктовка. В чужое окно текст попадает через буфер обмена и Ctrl+V; в историю буфера он не записывается, а прежнее содержимое буфера (текст, картинка, файлы) возвращается примерно через секунду после того, как окно приняло вставку. Если окно не откликается или это удалённый рабочий стол либо виртуальная машина, продиктованный текст так и остаётся в буфере. Если распознавание Windows недоступно, Glint нажимает Win+H — дальше работает голосовой ввод самой Windows со своими настройками.

Заметки лежат в `%AppData%\Glint\notes` (по файлу RTF на заметку, открываются и в WordPad, плюс `index.json` с папками и текстом для поиска), напоминания — в `reminders.json`. Всё без шифрования и только на этом компьютере.

Индикаторы, которые ходят в сеть, по умолчанию выключены и работают только после включения в «Настройки → Индикаторы»:

- **Текст песни** — запрос к `lrclib.net` с исполнителем, названием и длиной текущего трека.
- **Внешний IP и страна при VPN** — при каждом подключении VPN запрос к `ipwho.is` (если не ответил — к `api.country.is`); сервис видит ваш внешний IP.
- **obs-websocket** — соединение только с `127.0.0.1` на вашем компьютере, наружу ничего не уходит.

Индикатор **уведомлений Windows** (тоже выключен по умолчанию) читает системное хранилище уведомлений `%LocalAppData%\Microsoft\Windows\Notifications\wpndatabase.db` только для чтения: официальный API для этого требует упакованного приложения. Glint показывает лишь приложение и заголовок и ничего не сохраняет. Остальные индикаторы работают локально: реестр конфиденциальности Windows, папка «Загрузки», файлы Steam и OBS, список сетевых адаптеров.

**Инструменты экрана** (Настройки → Экран) работают без сети. Скриншоты сохраняются в «Изображения\Glint» только по кнопке «Сохранить» (или сразу, если редактор выключен), записи — в «Видео\Glint». Распознавание текста — офлайн-движок Windows (`Windows.Media.Ocr`), QR-коды читает встроенная библиотека ZXing.Net. Звук для записи берётся из устройства вывода по умолчанию (WASAPI loopback), микрофон не пишется. Пока Glint делает снимок или запись, его окна помечены как «не захватывать» (`SetWindowDisplayAffinity`), поэтому другие программы записи на это время тоже их не видят; на время записи Glint создаёт устройство Direct3D для видеокарты и закрывает его после.

**Пульт** в сеть не ходит: Wi-Fi и Bluetooth переключаются через системный API радиомодулей, список наушников берётся из сопряжённых устройств Windows, VPN — из телефонной книги Windows (`rasphone.pbk`) и подключается системной утилитой `rasdial` с сохранёнными в Windows учётными данными (если их нет, откроется системное окно входа). Кнопка темы Windows меняет в реестре `HKCU\...\Themes\Personalize` значения `AppsUseLightTheme` и `SystemUsesLightTheme` — то же, что переключатель в «Параметрах». Режим темы «как в Windows» только читает эти значения.

**Агенты** (Claude Code, Codex) в сеть не ходят. Агент на каждое событие запускает `Glint.exe --agent-hook claude` (или `codex`), тот читает JSON события и передаёт его работающему Glint по именованному каналу `\\.\pipe\Glint.Agents.<SID>`: доступ к нему есть только у вашей учётной записи, сетевые входы запрещены, а клиент проверяет, что канал принадлежит вам. Glint держит в памяти папку проекта, состояние, текст запроса и первую строку ответа и ничего из этого не записывает на диск. Чтобы показать кнопку «Показать терминал», Glint один раз на сессию смотрит список процессов (кто запустил хук). Ответ из пилюли уходит агенту в формате его хуков («разрешить» / «запретить» / ответы на вопрос). Файлы агентов (`.claude\settings.json`, `.codex\config.toml`) Glint меняет только по кнопке «Подключить» или «Отключить», после того как показал изменения, и каждый раз сохраняет копию прежнего файла рядом.

**Персонаж** в сеть не ходит и ничего не записывает, кроме вашего выбора в `settings.json`. Пока пилюля на экране, он смотрит, где курсор (дважды в секунду, а пока курсор движется рядом с пилюлей — около 16 раз в секунду), раз в 15 секунд (во сне — раз в секунду) спрашивает у Windows, сколько времени прошло с последнего нажатия или движения мыши (`GetLastInputInfo`: только время, без самих клавиш), а пока танцует — общий пиковый уровень устройства вывода (тот же индикатор, что рисует регулятор громкости Windows; звук не записывается и не анализируется дальше одного числа). Состояние агентов он берёт из раздела «Агенты», если они подключены.

История буфера обмена (текст и картинки) хранится на диске **без шифрования** в `%AppData%\Glint` (`clipboard.json` и папка `clips\`) и сохраняется между перезапусками. Содержимое, которое менеджеры паролей помечают как приватное, не сохраняется, но пароль, скопированный из обычного поля, попадёт в историю. Удалить её можно кнопкой «Очистить» во вкладке «Буфер» или удалив эту папку; отключить историю — выставив `ClipboardHistoryLimit` в `0` в `settings.json`.

## English

**Glint** is a small floating pill at the top center of the screen for Windows 10/11. It shows the clock, what's playing, the weather and live indicators, hosts a small character, and expands on hover into a panel with quick tools.

**Features:**

- **Pill:** clock, album art and a playback indicator (it also reacts to players that don't register with Windows media controls, by noticing which app makes sound), short flash messages, Glint's own weather icon and temperature, live indicators and synced lyrics.
- **Character** (Settings → "Персонаж"): seven original characters drawn by Glint (a round blob, a whiskered big-eared creature, a ghost, a robot with a screen face, a glossy slime, a star, a bean sprout) or none, at either end of the pill, in three sizes, optionally in the theme's accents. Its eyes follow the cursor when it is near the pill; it blinks and glances around; it dances to whatever is playing (hops on peaks of the output level, sways, sings, now and then a note); it thinks while Claude Code or Codex works (thought dots), shows "!" when an agent waits for you, cheers when it finishes and frowns at an error; it falls asleep (closed eyes, Zzz) after 2–30 minutes without input (an agent that has been silent as long doesn't keep it up) and wakes on the first move or a new agent event. CPU-wise it draws nothing while nothing changes, animates at most 24 fps and only in its own small box (the dance shares the equalizer's frames), stops completely while the pill is hidden, expanded, showing a flash or the session is locked, and freezes after a minute of sleep. On by default; pick "Нет" to remove it.
- **Hover panel** with tabs: Home, Clipboard, Shelf, Text, Notes, Weather, System, Control, Agents (once an agent is connected), Settings; it can be pinned open, and tabs become icon-only when the header is crowded.
- **Home:** media controls and volume; a 3×3 grid of quick actions (screenshot, full screen, screen recording, text from screen, QR, eyedropper, command bar, lock, Downloads folder); the next reminders; a dock of pinned apps (the + button, drag a shortcut onto it, or right-click an app in the command bar).
- **Screen tools** (Home, the command bar's "скриншот", "весь экран", "qr", "текст с экрана", "пипетка", "запись", and the tray menu), all working on a frozen snapshot where you drag an area, click a window or press Enter for the whole monitor, with Glint kept out of the picture:
  - screenshots with a markup editor (pen, highlighter, arrow, rectangle, ellipse, text, pixelate, crop, colours, sizes, undo/redo; copy, save PNG to Pictures\Glint, save as PNG/JPEG; the editor can be turned off);
  - QR and barcode reading with copy / open link / Wi-Fi password;
  - offline text recognition with the Windows OCR engine (Russian and English together; copied automatically and editable);
  - an eyedropper with a pixel-grid loupe and HEX/RGB;
  - screen recording of a monitor or an area to MP4 (hardware H.264 when available, optional system sound as AAC, 30 or 60 fps, saved to Videos\Glint) with a red dot and timer in the pill that stops it on click.
- **Clipboard history** with search, pinning and click-to-paste; **file shelf** with drag in/out.
- **Notes** tab: folders, search across all notes, a formatted editor (bold/italic/underline/strikethrough, headings, bulleted and numbered lists, checklists, theme-accent text colours), autosave to one RTF file per note with atomic writes, undo for deletes.
- **Alt+Space command bar:** apps, files, calculator, timers, natural-language reminders in Russian and English ("напомни завтра в 9 ...", "remind me tomorrow at 9am to ...") that survive restarts and are listed on Home and in Notes → Reminders with cancel buttons, opt-in currency conversion and rates ("100 usd", "курс евро"), quick notes ("заметка ...") and note search, weather ("погода"), dictation ("диктовка" and a mic button), screen tools, web search.
- **Text tools:** keyboard layout fix, transliteration, case, JSON, Base64, dictation into the editor.
- **System load** tab: CPU total/per-thread/clock, GPU, RAM, disks, network, top processes, one-minute graphs; GPU temperature, VRAM, power and fan on NVIDIA; no CPU temperature, since Windows only exposes it to kernel drivers; sampling runs only while the tab is open.
- **Control centre** ("Пульт") tab: Wi-Fi and Bluetooth on/off, one-press connect/disconnect for paired Bluetooth headphones and speakers, Windows VPN connections with connect/disconnect, Windows dark/light switch and Glint theme switch; read only while the tab is open.
- **Live pill indicators**, each with its own toggle: microphone/camera in use, Caps Lock and keyboard layout flashes, browser and Steam downloads with a clickable "downloaded" flash, OBS recording via the recording folder or optional obs-websocket, VPN badge with optional public IP/country, optional mirroring of Windows notifications, optional synced lyrics from lrclib.net.
- **Weather** (opt-in, Open-Meteo): a "Погода" tab with conditions now, a 24-hour strip with precipitation chance and a 7-day forecast; city search with Russian names; the icon and temperature next to the clock, taking turns with the clock when the pill is crowded; a one-per-rain "Через ~40 мин дождь" warning about an hour ahead from the 15-minute precipitation forecast; refreshed every 30 minutes while enabled and cached in `weather.json`.
- **Voice input:** a mic button in the Text tab and the command bar, the "диктовка" command and an optional global hotkey that dictates into the window you were typing in (pasted the same way clipboard history pastes, the previous clipboard content is restored about a second after the window takes the paste), with a pulsing mic and the phrase being heard live in the pill. It uses Windows speech recognition; when Windows lacks a speech language or online speech recognition is off, Glint explains what to enable, opens the right Settings page on click and falls back to Windows voice typing (Win+H).
- **Coding agents** (Claude Code and Codex, off until connected in Settings → "Агенты"): a chip next to the clock with the most urgent session's project folder and state (working, waiting for you, done, error; the dot breathes slowly while it works); an "Агенты" tab listing every session with a "show terminal" button; permission requests shown as a card in the pill with Allow / Always (the rule Claude Code itself suggests) / Deny / "ask in terminal"; Claude Code's multiple-choice questions answered with buttons; several requests queued one after another; a configurable wait (2 minutes by default) after which the agent asks in its terminal as usual; no interception while the agent's terminal is in front; clickable "done" / "waiting for you" flashes that bring the terminal forward. "Connect" shows exactly what will be added before merging Glint's hooks into `~/.claude/settings.json` or the hooks and `notify` into `~/.codex/config.toml`, keeps a timestamped backup, leaves all other settings and hooks alone, is idempotent, and "Disconnect" removes only Glint's entries (Codex runs new hooks only after you trust them in `/hooks`). When Glint isn't running the hook exits in milliseconds with no output, so the agent behaves as if Glint weren't there.
- **Looks and behaviour:** colour themes (dark, light or follow Windows; seven presets, custom HEX accents, background tint and opacity, applied live without a restart, tray icon and menu included; pale accents are darkened slightly in light mode so text stays readable); pill size 80–200%, hover delay, dragging the pill along the top edge; hiding in fullscreen and selected apps; auto-hide (the pill slides up behind the top edge leaving a thin strip and comes back on hover or any message); click-through mode (hold Ctrl over the pill to reach it; the tray menu can always turn it off and open Settings).
- **Tray icon** with screenshot, screen recording, Notes, Weather, Control, Agents, Settings, click-through, autostart and a found-update item; optional automatic update check.

**Download:** [Glint.exe](https://github.com/sempik/glint/releases/latest/download/Glint.exe) — a single self-contained file, no installer and no .NET runtime needed. It isn't code-signed, so SmartScreen may warn on first run ("More info" → "Run anyway"). Release builds are produced by GitHub Actions from this repository. To update, use Settings → "Проверить обновления": Glint downloads the latest release, checks its SHA-256 and restarts itself. An optional automatic check (off by default) looks at launch and every 6 hours and shows a clickable "Доступно обновление" flash; installing still needs your click.

**Requirements:** Windows 10 19041+ or Windows 11, x64.

**Build:** install the .NET 8 SDK, then run `dotnet build`, or
`dotnet publish src/Glint/Glint.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish`.

**Privacy:** all data stays on your machine in `%AppData%\Glint`. No telemetry; the only network requests are the ones you start (web search, the update button), the opt-in automatic update check (one request to `api.github.com` at launch and every 6 hours, which reveals your IP and Glint version), opt-in currency rates in the command bar (Bank of Russia rates from `www.cbr-xml-daily.ru`, fallback `open.er-api.com`, fetched only when you type a currency query and at most every 6 hours, cached in `rates.json`) and the opt-in indicators: synced lyrics (track artist/title/length sent to `lrclib.net`) and the VPN public IP lookup (`ipwho.is`, fallback `api.country.is`), and opt-in weather: the city search sends what you typed to `geocoding-api.open-meteo.com` only when you press "Найти", and the forecast request sends only the city's coordinates to `api.open-meteo.com` at launch (when the cached forecast is older than 30 minutes) and every 30 minutes while weather is on; nothing runs while it is off. Voice input runs only on your press: Windows does the recognition (with "Online speech recognition" on, Windows sends the audio to Microsoft under its own terms); Glint itself never records, stores or sends audio, keeps the microphone open only while dictating, and pastes into other windows through the clipboard without adding the text to its history, restoring the previous clipboard content about a second after the window has taken the paste (except in remote-desktop and VM windows or a window that stops responding, where the dictated text stays on the clipboard). obs-websocket talks to `127.0.0.1` only, and its password is stored encrypted with DPAPI. The opt-in notification mirror reads the Windows notification store (`wpndatabase.db`) read-only, because the official listener API requires a packaged app; only the app name and title are shown and nothing is stored. The screen tools work offline: OCR uses the built-in Windows engine, QR codes are decoded by the bundled ZXing.Net library, recordings capture the default output device via WASAPI loopback (never the microphone), and while Glint takes a snapshot or records, its own windows are marked "exclude from capture" (`SetWindowDisplayAffinity`), so other capture apps don't see them during that time either. The control centre works offline: radios via the Windows radio API, paired Bluetooth devices from Windows, VPN profiles from the Windows phonebook (`rasphone.pbk`) dialled with `rasdial` and the credentials Windows has saved, and the Windows theme button writes `AppsUseLightTheme`/`SystemUsesLightTheme` under `HKCU\...\Themes\Personalize`, like the Settings app does. The coding-agent integration makes no network requests: the agent starts `Glint.exe --agent-hook claude|codex` for each event, which forwards the event JSON to the running Glint over the named pipe `\\.\pipe\Glint.Agents.<SID>`, whose ACL admits only your Windows account (network logons denied; the client also checks the pipe's owner); Glint keeps the project folder, state, request text and the first line of the answer in memory only, looks at the process list once per session to find the agent's terminal, and changes the agents' config files only when you press Connect or Disconnect after seeing the change, with a backup each time. The character makes no network requests and stores nothing but your choice in `settings.json`; while the pill is on screen it reads the cursor position (twice a second, about 16 times a second while the cursor moves near the pill), asks Windows every 15 seconds (every second while asleep) how long ago the last input was (`GetLastInputInfo`: a time only, never the keys), and while dancing reads one number, the output device's peak level (the meter the Windows volume flyout draws; no audio is recorded). Notes (`notes\` with one RTF file per note plus `index.json`) and reminders (`reminders.json`) are stored unencrypted on this machine. Clipboard history (text and images) is stored **unencrypted** there (`clipboard.json` and `clips\`) and survives restarts. Content that password managers mark as private is not saved. Use "Очистить" in the clipboard tab or delete the folder to remove it.
